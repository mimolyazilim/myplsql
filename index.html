Write, run and debug Oracle SQL and PL/SQL on your Mac.

MYPLSQL is a fast desktop IDE for Oracle Database developers: browse schema objects, edit packages, run scripts and step through PL/SQL code — with the function keys you already know.

Mac App Store Get support

Free 30-day trial with every feature. Then a one-time purchase (MYPLSQL Lifetime) — no subscription.

Features

  • SQL Window — run statements and scripts (F8), result grid, explain plan, statement history
  • Program Window — edit and compile packages (spec & body), procedures, functions, triggers and types
  • Object Browser — tables, views, packages, sequences, synonyms, database links… with right-click actions
  • PL/SQL Debugger — breakpoints, step into / over / out, variable values
  • Test and Command windows, table editor, PL/SQL beautifier
  • Several connections at once, each window with its own session
  • Configurable shortcuts: F8 execute, F10 commit, ⇧F10 rollback, ⇧Esc break
  • Connects directly to Oracle Database 12.1 and later — no Oracle Client installation needed

Which Oracle versions are supported?

The Mac App Store version connects to Oracle Database 12.1 and later, directly over the network (no Oracle Client needed). Use an EZConnect string such as host:1521/service, or a TNS alias from your tnsnames.ora.

How do I use my tnsnames.ora?

MYPLSQL → Preferences → TNS_ADMIN → Browse… and choose the folder that contains tnsnames.ora. macOS lets the app read only folders you choose this way.

What happens when the trial ends?

The app keeps working with your files and settings, but logging on to databases requires MYPLSQL Lifetime, a one-time purchase. Buy it from MYPLSQL → Buy MYPLSQL / License…
